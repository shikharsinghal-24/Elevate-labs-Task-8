# 📊 Task 8 - Simple Sales Dashboard Design

**🎯 Objective:**  
Create a basic interactive dashboard showing **sales performance by Product Category, Region, and Month** using Power BI.

---

## 📁 Dataset Used
- **File:** `Superstore_Sales.csv`  
- **Columns:**  
  - `Order Date`  
  - `Region`  
  - `Category`  
  - `Sales`  
  - `Profit`  
- **Rows:** 10,000 (synthetic large dataset)

---

## 📊 Dashboard Features

- **Line Chart:** Sales trend over time (Month-Year)
- **Bar Chart:** Sales distribution by Region
- **Donut Chart:** Sales by Product Category
- **Slicer/Filter:** Region

---

## 📈 Key Insights
1. **West region** showed the highest total sales.
2. **Technology** category contributed the largest share in revenue.
3. Sales showed steady growth from **2021 to 2023**, peaking in Q4.
4. The **South** region, while lower in total sales, had consistent quarterly growth.

---

## 🧰 Tools Used
- **Power BI** (for dashboard creation)
